# Pixel Art GIF with Python 🐍🎨

This project combines **art + code** — I drew simple pixel art on my phone, then used Python to turn it into animated GIFs.  

Inspired by [Codédex – Create a GIF with Python](https://www.codedex.io/projects/create-a-gif-with-python).

---

## ✨ Features
- Pixel art created on mobile
- Python script to load images and convert them into a GIF
- Resizing support (so all images fit perfectly)
- Simple and fun example of **creative coding**
